## 📖 О приложении

**FourteenPlayer** — это стильный и производительный музыкальный проигрыватель для Windows, объединяющий эстетику реалистичного тактильного интерфейса («тёмный титан и полированный изумруд») с глубокой системной интеграцией Windows.

Плеер создан для тех, кто ценит скорость, минимализм и удобство управления: он моментально запускается, не нагружает процессор и оперативную память, отображает текущий трек в системном меню громкости Windows, транслирует активность в Discord и позволяет управлять музыкой как из красивого интерфейса, так и в фоне с клавиатуры.

## ✨ Ключевые возможности

### 🔊 Нативная интеграция с Windows (SMTC)
* При изменении громкости в Windows появляется всплывающее системное окно с иконкой плеера, названием текущего трека, исполнителем и альбомом.
* Полноценное управление через медиаклавиши клавиатуры и гарнитур (Play, Pause, Next, Prev, Stop).

### 🎮 Интеграция с Discord (Rich Presence)
* Отображение прослушиваемой музыки в реальном времени в статусе профиля Discord («Слушает FourteenPlayer»).
* Первая строка карточки — название трека (жирным шрифтом), вторая — исполнитель.
* При паузе трек аккуратно скрывается, отображая спокойный статус «Пока что подождем....».
* Отдельная вкладка настроек в плеере с возможностью включения/отключения и указания своего Discord Application ID.

### 🎛 Премиальный тактильный интерфейс
* Глубокая тёмная палитра с эффектом матового металла и изумрудными акцентами (#10B981).
* Полная оптимизация рендеринга: чёткие векторные границы и шрифты без малейшего мыла на мониторах любого разрешения и масштаба (100%, 125%, 150%, 4K).
* **Интерактивные ползунки**: мгновенный переход в любую точку трека или громкости по клику мыши и плавное перетаскивание бегунка в реальном времени (60 FPS).
* Управление громкостью колёсиком мыши с шагом в 5%.

### ✏ Переименование файлов прямо на диске
* Возможность переименовать файл прямо из плейлиста (по нажатию `F2`, кнопке `✏` или через контекстное меню).
* **Защита расширения**: при редактировании доступно только само название аудиозаписи, расширение сохраняется в первозданном виде.
* Если трек играет в момент переименования, плеер бережно освобождает файл, переименовывает его на диске и плавно продолжает воспроизведение с той же секунды.

### ⚡ Сверхнизкое потребление ресурсов
* Оптимизированный аудиотракт: загрузка центрального процессора находится на уровне **~0.0%**.
* Встроенный монитор ресурсов в нижней строке состояния отображает актуальное использование ОЗУ и ЦП в реальном времени.

### 🔄 Богатые режимы воспроизведения
* **Shuffle (🔀)**: случайный порядок треков без повторений.
* **Повтор всего списка (🔁)**: непрерывное циклическое воспроизведение плейлиста.
* **Повтор альбома / папки (💿)**: зацикливание только текущего альбома.
* **Повтор одного трека (🔂)**: бесконечное прослушивание любимой композиции.
* **Без повтора (➡)**: остановка после последнего трека.

### 📥 Фоновая работа в системном трее
* При нажатии на крестик окно сворачивается в область уведомлений (системный трей), продолжая воспроизведение.
* Контекстное меню трея для мгновенного разворачивания или выхода из приложения.

### 🔍 Умный поиск и работа с медиатекой
* Мгновенный фильтр плейлиста по названию, автору или альбому.
* Drag & Drop: просто перетащите файлы или целые папки прямо в окно плеера.
* Чтение метаданных ID3v1 / ID3v2 и автоматическое извлечение названий.
* Поддержка всех форматов: **MP3, WAV, FLAC, M4A, AAC, WMA, OGG**.

### 🚀 Автоматическая проверка обновлений
* При каждом запуске плеер автоматически проверяет наличие свежих релизов на GitHub.
* При появлении обновления строка статуса сообщает: *«Вышло обновление! Попробуешь?»* со ссылкой на страницу загрузки в один клик.

## 📋 История обновлений

### 🌟 Версия 2.1.2 / 2.1.1 / 2.1

* **🎮 Интеграция с Discord Rich Presence**:
  * В профиле Discord отображается статус *«Слушает FourteenPlayer»*.
  * В карточке активности: первой строкой жирным шрифтом выводится название песни, второй строкой — имя исполнителя.
  * При постановке на паузу название трека и застывшие таймеры скрываются, отображая заготовку *«Пока что подождем....»*.
  * При зацикливании одного трека (повтор) устранён баг с зависанием на последней секунде: таймкод Discord мгновенно перезапускается с 0:00.
  * В меню «Настройки» добавлена вкладка **«🎮 Discord RPC»**: переключатель активности и поле для ввода кастомного Discord Application ID.

* **🎚 Плавное интерактивное управление ползунками (Seekbar & Volume)**:
  * Устранено ограничение, при котором двигать слайдер можно было только за бегунок (Thumb).
  * Теперь клик в любую точку шкалы времени или громкости моментально перемещает бегунок, а при зажатии мыши происходит плавное перетаскивание на частоте 60 кадров/сек.

* **🔊 Исправление Windows SMTC (системный оверлей)**:
  * Исправлена проблема, при которой в оверлее громкости Windows отображалось только *«FourteenPlayer.exe»*.
  * Воспроизведение переведено на `MediaPlaybackItem` с заполнением метаданных (Title, Artist, Album, Thumbnail) и вызовом `DisplayUpdater.Update()`. Теперь системный оверлей Windows всегда отображает название трека, исполнителя и кнопки управления.

* **📦 Новый Modern Dark инсталлятор (Setup)**:
  * Полностью устранён раздражающий белый фон в шапке окна инсталлятора.
  * Реализован кастомный установщик в темно-изумрудном стиле (#181D2A), с поддержкой тёмного заголовка Windows DWM, кастомным прогресс-баром и режимом тихой установки (`/S`).

* **⚡ Критическое исправление запуска (v2.1.2)**:
  * Устранена ошибка XAML-парсера при старте приложения, связанная с ресурсом `SearchTextBox`. Восстановлен моментальный запуск плеера.

### 💎 Версия 2.0 (v2.0.beta & v2.0.release)

* **🔊 Нативная системная интеграция (Windows SMTC)**:
  * Внедрена поддержка системного транспорта Windows (System Media Transport Controls).
  * Интеграция со всплывающей плашкой громкости Windows и мультимедийными клавишами клавиатур/гарнитур (Play/Pause, Next, Prev, Stop).
  * Фоновое воспроизведение при сворачивании приложения в системный трей.

* **✏ Переименование аудиофайлов прямо на диске (F2)**:
  * Возможность переименовывать файлы прямо из интерфейса (F2, контекстное меню, иконка карандаша).
  * Защита расширения: редактируется только имя, расширение не может быть случайно стёрто.
  * Бесшовное переименование: если файл воспроизводится, плеер на мгновение освобождает дескриптор, меняет имя на диске и продолжает играть с той же миллисекунды.

* **🎨 Новый тактильный дизайн (Dark Emerald)**:
  * Полный отказ от размытого интерфейса: идеальная чёткость шрифтов и векторных рамок на любых разрешениях мониторов и масштабировании Windows (SnapsToDevicePixels, ClearType).
  * Реалистичные кнопки с эффектом объёмного нажатия и акцентом изумрудного свечения (#10B981).

* **🔊 Исправление и стабилизация громкости (v2.0.release)**:
  * Устранена проблема со сбросом звука на 50% при открытии следующего файла в системном компоненте MediaPlayer.
  * Устранён скачок звука при первом движении ползунка громкости. Громкость синхронизирована на 100% при всех видах переключения треков.

* **🔄 Режимы воспроизведения и управление**:
  * Реализованы режимы Shuffle (случайный порядок без повторов) и 4 режима Repeat (все треки, текущий альбом, один трек, без повтора).
  * Плавное изменение громкости колёсиком мыши с шагом 5%.
  * Полный набор горячих клавиш (Space, стрелки, Ctrl+стрелки, Mute, F2 и др.).

* **🚀 Автоматическая проверка обновлений**:
  * Фоновая проверка новых версий на GitHub при запуске плеера с ненавязчивым индикатором в статусной строке.
  * Раздел «О программе» и модальное окно истории версий.

* **📦 Автономный установщик FourteenPlayer Setup**:
  * Собственный установщик в темно-изумрудном дизайне с установкой в `%LocalAppData%\Programs\FourteenPlayer`, созданием ярлыков и регистрацией в системе Windows.

## ⌨ Горячие клавиши

| Клавиша / Жест | Действие |
| :--- | :--- |
| **Пробел** | Воспроизведение / Пауза |
| **← / →** | Перемотка назад / вперед на 5 секунд |
| **Ctrl + ← / →** | Предыдущий / Следующий трек |
| **↑ / ↓** | Увеличение / уменьшение громкости на 5% |
| **Колесо мыши** | Плавная регулировка громкости |
| **F2** | Переименовать выбранный файл на диске |
| **M** | Быстрое отключение звука (Mute) |
| **S** | Включение / выключение случайного порядка (Shuffle) |
| **R** | Переключение режимов повтора (Все / Альбом / Трек / Выкл) |
| **Delete** | Удаление выбранного трека из плейлиста |
| **Enter / Двойной клик** | Запуск выбранного трека |
| **Esc** | Закрытие открытых окон настроек и диалогов |

## 🛠 Технологический стек

* **Язык**: C# 13 / .NET 9.0
* **Интерфейс**: Windows Presentation Foundation (WPF) с кастомным рендерингом XAML
* **Системная интеграция**: Windows Runtime (WinRT) `SystemMediaTransportControls` (SMTC), Discord Game SDK / RPC
* **Аудиодвижок**: Hardware-accelerated Media Foundation
* **Платформа**: Windows 10 (19041+) / Windows 11

## 📥 Установка и запуск

1. Перейдите в раздел [Релизы на GitHub](https://github.com/muzdilapills/FourteenPlayer/releases).
2. Скачайте инсталлятор **`FourteenPlayer_v2.1.2_Setup.exe`**.
3. Запустите установщик — он автоматически установит плеер и создаст ярлыки на Рабочем столе и в меню Пуск.
4. Запустите плеер и наслаждайтесь любимой музыкой!
